# 镇纸六屏搬进 DeepSeek Harness —— 完整计划（业务版 v1）

2026-08-16 ｜ 状态：待琴疏拍板 ｜ 依据：简报 35 调研（out/35a 技术地图、out/35b 产品映射）

## 这件事是干什么的

镇纸现在的数据和屏都在自己家里（大屏 4317、SQLite、68 条 API），但要跟 AI 商量事就得两头跑，之前养的自建 agent 又太费心、不养了。这个计划做的事：把镇纸的六个屏——押注台、金子墓碑库、协作台、观众声音、运维数据源、大盘笔记——**作为插件装进 DeepSeek Harness（dsh）**。以后你在 dsh 一个窗口里，@一张真实押注卡就能跟 AI 讨论"这注数据够不够裁"，AI 引用的全是镇纸真数据；镇纸大屏照旧挂墙上看，一个像素都不用改。

怎么算成了：你在 dsh 里聊任何一条真实押注、判决、观众评论，AI 引用的数据都能点回镇纸复核；**AI 永远不能替你下判决**——裁决、确认永远是你亲手点；全天下只有镇纸一份数据，dsh 不抄第二份。

## 你分期得到什么

### P0 · 先把"判的对象"放进对话（押注台 + 金子墓碑库）

你得到的：
- dsh 左栏多一个「押注」页：在途押注列表，点开看单卡（赌注、置信度、离结账几天、最新回流数据、相关判例）
- 聊天框里 `@押注卡`：这张卡的全部背景自动摆进对话，AI 看着真数据跟你聊
- `/bets` 命令：随时列出在途押注
- 五个"查数"工具给 AI 用：查押注、查数据文档、查判决、查判决证据、查文档版本——**全是只读，AI 手里没有任何"确认/裁决"按钮**
- 金子墓碑一个轻量页：金句、墓碑能看能搜，聊天里也能 @引用

这一期几乎全是"看"和"引用"，不动任何写操作，所以风险最小、最快能用上。

### P1 · 把"每天早上的那一眼"搬进 dsh（今日值得看 + 观众声音 + 起草）

前提：P0 你真的用起来了（不是演示）。
你得到的：
- dsh 左栏多一个独立的「镇纸」区（就像参考图里「会话」和「内容」并排两个 tab）：**定时推送的分析结果和内容全部进这个区，不以新会话的形式混进日常对话列表**
- 早上打开这个区，就是昨夜筛好的候选卡，可以挑、可以改、可以否（你亲手点）
- 观众声音摆盘：评论按主题分桶，逐字原文带赞数展开
- AI 能**起草**押注卡了——但只是草稿，躺在你面前的提案区，你点确认才算数（系统记得清清楚楚哪笔是 AI 起草、哪笔是你定的）

### P2 · 收口（通知 + 笔记 + 品牌）

- 押注到期、该裁决了，提醒进左栏「镇纸」区（带未读标记），同样不占对话入口——手机用域名打开 dsh 就能收到和处理，**不再绕微信那一层**
- 聊某注押注时，相关的旧笔记自动到场（Memos 只读的规矩不动）
- dsh 里的镇纸页面换成纸感浅色，跟大屏一个调性

## 永远不做的事

AI 可调用的裁决/确认工具；dsh 里存第二份数据；深色数据板皮肤；看板/日历/甘特图；卡片上出现"推荐"两个字。

## 数据纪律（三条军规，说人话版）

1. **一份真身，一个门。** 数据只在镇纸，dsh 插件要数据一律走 4317 的门，不撬锁（不直连数据库文件）——因为"数据只增不改""草稿不进正式区"这些规矩都守在大门口，绕过去就等于另立规矩。
2. **写操作只有两种能发生**：AI 写草稿（躺在提案区等你点），和你亲手点按钮。没有第三种。
3. **两本账对得上。** 镇纸记镇纸的账，dsh 记 dsh 的账，中间靠"草稿哈希 + 时间戳"勾稽——AI 起草的东西被你确认时，谁起草的、谁确认的，一目了然。

## 先装的地基：插件管理（社区现成）

装一个"管插件的插件"：社区的 **dsh-plugin-marketplace**（AwesomeHou，MIT）。它干的事：

- 在「设置 → 插件」里多一个市场页，能看**当前装了哪些第三方（非官方）插件**、启用状态、版本、有没有新版可升，一键安装/更新/卸载
- 以后镇纸这六个自研插件装进去，都归它管——哪些是官方的、哪些是自己装的、有没有更新，一眼看清
- 顺带它还把 GitHub 上 1800+ 个社区插件做成了可搜索的市场，以后找轮子不用出 dsh

## 谁干什么

- 插件的数据层（工具、接口对接）：派 dsh 窗口施工
- 插件的界面（左栏页、卡片详情）：**kimi 主控亲手做**（这是定死的规矩，前端不外派）
