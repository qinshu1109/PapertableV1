## ② 会话免打扰

| 项 | 结论 |
|---|---|
| 桌面会话列表 | 「琴疏的智能助手」行 **没有** 静音铃（对比：「Kimi Code用户群」有铃） |
| `GET /open-apis/im/v1/chats/:chat_id` | `chat_mode=p2p`，`chat_status=normal`；返回体 **没有** 用户侧免打扰字段 |
| `GET .../chats/:id/mute` 与 `.../members/me_mute` | **HTTP 404**，开放平台没有可读的「用户把这个单聊设了免打扰」接口 |

因此：会话免打扰 **只能用户在手机上点开看**。grok 不能远程开关。

## ③ 飞书 App 内通知设置

依据帮助中心《设置消息通知》移动端页（https://www.feishu.cn/hc/zh-CN/articles/111093338362）：

- 入口：手机飞书 **头像 → 设置 → 通知**。
- **收到以下消息时通知我**：要「全部新消息」。若是「部分新消息」，点右侧编辑，**单聊消息**必须勾上（机器人是单聊）。不要选「全部不通知」。加急消息官方默认勾死，跟普通横幅无关。
- **关闭手机通知**：说明原文「当飞书桌面端或 iPad 端在线时，当前设备不接收新消息通知」。FAQ 也写：电脑在线时手机不弹，就是这项。本机桌面飞书仍在线 → **这项必须关掉**。
- **收不到消息通知或通知延迟？**（仅安卓）：点进去 → 开 **常驻通知栏**、**关闭电池优化**、点 **后台允许权限** 的「去设置」。
- **消息通知故障诊断**：会发一条测试消息。结论原话发回来。
- **声音与震动**：普通消息不要静音。

## ⑤ 文档核实（开放平台）

| 问题 | 核实结果 |
|---|---|
| 自建应用机器人消息怎么推到手机 | `POST /im/v1/messages` 把消息写入会话；客户端按用户通知设置弹。API **没有** `push` / 静默字段可开关普通横幅。 |
| interactive 卡片 vs text | 都进同一会话、走同一套客户端通知。没有「卡片不推送」的接口字段。本简报已发 1 条 text 对照，手机会话里看得到，仍不弹 → 不是卡片类型问题。 |
| `urgent_app` | `PATCH /im/v1/messages/:id/urgent_app`，权限 `im:message.urgent`。这是 **额外加急（Buzz）**，不是普通横幅的开关。P0 要普通到达率，**不要**用加急凑数。短信/电话加急是另两个权限，更不要动。 |
| 电脑在线不弹手机 | 帮助中心 FAQ 原文指向「关闭手机通知」。 |

来源：发送消息 https://open.feishu.cn/document/server-docs/im-v1/message/create ；应用内加急 https://open.feishu.cn/document/server-docs/im-v1/buzz-messages/urgent_app ；帮助中心两篇上文已链。
