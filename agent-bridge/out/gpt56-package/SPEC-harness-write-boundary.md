## 1. 核心模型

**对话即控制台：AI 工具全开、决策权在人、人不动手、AI 不拿主意。**（2026-08-06 用户拍板）

- 决策 = 人在对话里下指令；执行 = AI 动手写入；页面按钮留作后路，不是人的义务。
- 与 2026-08-04 铸币权纪律的关系：实现方式从「能力级 deny」（工具不存在）升级为「发动权在人」（工具都在，须人发话才用）。防平庸条款（原文原则 / 异类保留 / 判断留人）不变——决策内容来自人，AI 只起草、摆盘、执行。

## 2. 长期调试原则

- 全部分档为 **v1 默认值**，按实际使用长期调试修订，修订权在人。
- 「不开放给 AI」一律含「保留人工干预空间」（curl / 脚本 / 按需补人工通路），不解释为永不开门。

## 3. 写动作分档表（v1 默认）

### AI 自主（不等指令）

| 动作 | 说明 |
|---|---|
| 起草押注 / 起草结账建议 | 既有；draft_hash 固化，转正走人发话档 |
| 筛子 run | 既有：到达去抖 + watermark 兜底 |
| 金子镜像同步 | 源=已确认金子，幂等搬运，零判断 |
| LLM 声音分拣 | 可重跑覆盖，原文不动 |
| 语料抓取 | **先抓后审**：AI 对话内直抓（非脚本）；行为限速=读风控信号自行放慢并反馈，撞墙 needs_human 交人；审后不设废弃 |

### 人发话 AI 干（对话执行）

押注草稿确认（可带修改）/ 驳回 · **结账（两跳合一跳：草案固化→人审→人说确认→AI 一步结掉，草案内容即结账内容）** · 直接建押注 · 挑卡 / 改挑 / 否卡 · 全否重筛 · 录入观众声音 · 挂载 / 摘除产出物 · 手动补筛 · 数据文档冻结 · 押注编辑（标题/指标/结账日）

### 不进对话（机制 / 脚本 / 低频）

抓取器与 B 站同步的状态回报 · 协作消息记录 · 审计落账 · 筛子水位推进 · 平台连接登记与状态变更（低频，UI 维持）

### AI 默认不开 · 人留后门

删押注（作废语义代之）· 改判决（作废重结代之）· 候选卡常规回退 · 筛子水位重置 · 协作消息删除 · 金子镜像强制刷新 · 风控记录清空（军规只增不清）· 声音→草稿提升链（留 P2）

## 4. 审计规格

每笔 AI 代办写入记四样：

1. **谁干的**（actor=AI，与人的手工动作分开；扩现行「actor=ai 仅草稿类」限制）
2. **干了什么**（动作 + 对象）
3. **听谁的话**（人的指令原话或消息引用——「发动权在人」的落账证据）
4. **什么时候**

配套：账本只增不改（延续 append-only）；**审计盲区全补**——语料抓取、观众声音、连接状态、金子镜像、协作消息全部纳入记账。

## 5. 撤销规格

| 办错什么 | 撤法 |
|---|---|
| 误确认草稿（已转正） | 作废该押注，需要就重新起草；不做「退回 draft」（转正后可能已挂数据，作废重开账才干净） |
| 误挑卡 | 【新造】**撤销挑卡**：生成的押注作废 + 候选卡退回待选（仅限撤销场景的冲正键，不开常规回退工具） |
| 误结账 | 【新造】**结账作废**：结账与判决一起作废，之后可重结（教材不涂改，只作废重铸） |
| 误录声音 | 软丢弃（既有通路） |
| 误抓取 | 不设（语料躺着不碍事） |
| 误编辑押注 | 再编辑即可（编辑可反复） |
| 误冻结 | 不解冻——要改就追加新版本 |

新造的冲正键仅两个：撤销挑卡、结账作废。

## 6. 监督规格（店规 A）

- **纪律**：无人明确指令，禁止调用写工具（提示词措辞留实现）。
- **擅自发动判定**：执行类账目缺人指令引用 = 擅自发动，无灰色地带；实现为自动断言，测试/冒烟专盯此条。
- **审查入口**：对话内问「你最近代办了什么」，AI 查账摆出（时间/动作/依据哪句话）；不做专门审计页面（真需要后补）。
- **失效升级**：抓到无引用账 = 店规突破信号 → 铸金级操作（结账/转正类）升硬闸门 B（写工具须引用人原话 + 后端校验）。平时不装，出事再装。

## 7. 指认规格

- **菜号牌**：AI 摆对象必贴短标签（证据 N / 注 N / 草稿 A / BV 号），对话与页面同一标签。
- **就近锚定**：「就这张」= 当前话题卡或唯一候选。
- **清楚就干，含糊才问**：指认明确 → 宣告即执行，不复述不等待；含糊 → 必反问，绝不猜。
- **单卡对话**默认锚定当前卡；**全局对话**必须先列候选再指认。
