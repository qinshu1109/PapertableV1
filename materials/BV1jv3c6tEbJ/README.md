## 视频核心机制（基于评论与视频内容解析）
这是一个基于 Agent 自动化生成「手绘涂抹动画」的工具与工作流（手绘动画3.0）：
- **核心原理**：整段视频其实是一张完整生成的图片/SVG，通过遮罩（Mask）把所有元素盖住；
- **手绘模拟**：通过自动化鼠标/画笔轨迹，将盖住的图层元素一点一点揭开（动态掩码）；

- **全自动流水线**：输入字幕 SRT/文案 → Agent 规划画面构图与出场时序 → 本地渲染引擎执行手绘揭示动画 → 合成输出成片。
