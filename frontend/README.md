# 纸桌 Papertable

本地优先的**图结构对话与知识探索工具**高保真交互原型。

一张卡片是一个相对独立的上下文容器，卡片之间的关系决定新对话继承什么。中央卡片堆叠表示当前探索路径，右侧关系图表示项目全局结构。

设计方向：**Warm Knowledge Desk / 暖色知识工作台**。

---

## 启动方式

```bash
npm install
npm run dev        # http://localhost:5173
```

构建与本地预览：

```bash
npm run build
npm run preview
```

技术栈：Vite + React 18 + TypeScript + 原生 CSS Variables + lucide-react + framer-motion。关系图为自绘 SVG，无图表库。

主要设计画布 1440×900，移动端基础布局按 390×844 完成。

## 已实现的交互

### 卡片与关系图联动

- 点击右侧关系图节点切换当前卡片，切换动画约 380 ms 弹性过渡；
- 中央堆叠随路径变化，最多露出 3 张祖先卡片的边缘，点击边缘返回上一级；
- 每张卡片保持自己的滚动位置，来回切换后恢复；
- 关系图支持拖拽平移、缩放、折叠子树、未读小点、悬停提示与「回到当前节点」。

### 三种关系

| 操作 | 语义 | 入口 | 继承策略 | 视觉方向 |
|---|---|---|---|---|
| 深挖 | Child | 卡片右上主按钮 / 底部中间 / 轮次工具条 / 选区工具栏 | 来源主题 + 选中片段 | 沿路径向下 |
| 发散 | Divergent | 底部右侧 / 轮次工具条 | 仅来源标题作为相关主题 | 向右展开 |
| 改道 | Branch | 底部左侧 / 轮次工具条「从此改道」 | 分支点之前的完整历史 | 向左分岔 |

三者在按钮位置、图标、中文短标签、连线颜色与新卡片进入方向上都不同。数据层统一用 `CardEdge` 表达，UI 不硬编码关系语义。

- 改道会先弹出**分支点选择器**，列出当前卡片的每一轮 AI 回复；
- 新的分支卡片顶部显示「从第 N 轮改道：来源标题」胶囊，点击可回到来源卡片并高亮分支点；
- 发散会弹出方向输入浮层，让用户写清楚要联想到哪里。

### 文本选择与精确引用

- 使用真实浏览器选区（`window.getSelection`），选中 AI 回复中的文字后在选区上方浮出「深挖 / 引用 / 复制」；
- 「引用」不会把文本拼进输入框正文，而是在输入器上方形成结构化引用胶囊；
- 胶囊显示来源卡片与截断引用，可删除、可连续添加、点击可定位回来源段落并高亮。

### 概念预览

- demo 正文中「量子退相干」「波函数」「希尔伯特空间」等词带虚线下划线，可点击；
- 弹出可拖拽浮层，模拟流式生成，包含来源句、引用、关闭与「展开为卡片」；
- 展开后预览内容成为正式卡片，来源信息与关系边一并写入图中。

### 本次上下文检查器

输入器上的「本次上下文」面板列出：

- 会带入什么（当前卡片轮次、来源主题、来源片段、继承到第几轮、每一条引用）；
- 不会带入什么（来源卡片的完整历史 / 分支点之后的内容 / 其他分支）；
- 模拟的上下文体积与预算条。

这是本原型相对参考产品最重要的一处改进：让隐式的上下文继承变成可审计的。

### 其他

- 模拟流式回答：发送后立即写入用户消息，定时器逐字输出，发送按钮变停止按钮，停止后保留已生成内容；
- 新建的深挖 / 发散 / 改道卡片会自动生成一条模拟回答；
- 可撤销删除：卡片及其下游进入回收站，底部 Toast 提供撤销；
- 侧栏可折叠为图标轨道，移动端变为抽屉；
- 导入笔记（单个 Markdown / Markdown 文件夹 / JSON Canvas / 无损项目包）与导出（Markdown 文件夹 / JSON Canvas + Markdown / 无损项目包）；
- 项目搜索、置顶、行内 `…` 菜单、项目删除可撤销；
- 移动端：抽屉侧栏、顶部横向迷你关系导航、轮次工具条常驻可见、输入器适配 `env(safe-area-inset-bottom)`；
- 尊重 `prefers-reduced-motion`。

## 哪些是 mock

本轮只验证前端交互，以下内容全部是本地 mock，不涉及任何网络请求：

| 项目 | 状态 |
|---|---|
| 模型调用 | 无。回答来自 `src/data/demo.ts` 的固定语料 + 定时器逐字输出 |
| 概念标注 | 卡片上的 `concepts: string[]` 常量，不是模型返回的结构化区间 |
| `buildContext()` | 未实现。上下文面板按关系类型静态推导展示，未真正拼装消息 |
| 持久化 | 无。全部状态在 React state 中，刷新后回到初始 demo |
| 导入 | 只表现格式选择与完成反馈，不解析真实文件 |
| 导出 | 只表现格式说明与完成反馈，不生成真实文件 |
| 附件 | 只有按钮与提示，不上传、不解析 |
| 项目搜索 | 只按项目名过滤，不检索卡片正文 |
| 收藏 | 卡片级收藏可切换；轮次收藏只有菜单项 |
| 回收站 | 软删除标记 + 6 秒撤销，没有独立的回收站界面 |

本轮明确**不包含**：登录注册、账户中心、订阅会员、额度倍率、账单支付、云项目云同步、多人协作、模型商城、落地页、服务端数据库、真实文档解析、完整设置中心。
