# 用户旅程：笔记价值闭环（纸桌 × 镇纸 × 后台捞料）

- 版本：v1（2026-08-11，对应 TASK-PW-61 / TASK-PW-62 已上线能力）
- 读者：琴疏，以及以后想搞懂"这套系统到底怎么转"的自己
- 一句话：你负责想和判，AI 负责每天把旧料翻出来送到押注旁边；用过的料升值，没用的料现形，写过的思考自动回流成以后能捞的笔记。

## 角色与道具

| 角色 | 干什么 | 不干什么 |
|---|---|---|
| 你（琴疏） | 想、押注、确认/弃、结账、拍板 | 不整理笔记、不记流程 |
| 纸桌 Papertable | 非线性探索：卡片、分叉、改道、判决（金子/墓碑） | 不做内容排期 |
| 镇纸 Paperweight | 内容生产：押注台、执行挂载、数据回流、结账、笔记大盘 | 不做存储 |
| 后台捞料员（DeepSeek） | 每天 06:30 按在途押注+当前方向捞旧料，只提候选 | 不决策、不评分、不写正式表 |
| Memos | 笔记唯一真值库 | —— |
| MemOS | 长期记忆（含判决远端记忆） | —— |

## 闭环总图

  └──────────┬───────────────┘      └───────────┬──────────────┘
             │ 金子墓碑同步 MemOS                 │ 笔记库变厚

## 主旅程：普通的一天

### 06:30 你还在睡，系统在跑

捞料员醒了。它先看镇纸里哪几张押注在途、当前方向是什么，然后翻三个矿：Memos 笔记（只读）、金子墓碑库、MemOS 记忆。翻完挑出一小把候选，每条写上"建议挂到哪张押注、为什么"。然后记台账：捞了几条、各来源几条、花了几分钱（超过 ¥0.10 自动收手）。

它不动任何正式数据。所有候选都只是"建议"。

### 09:00 你打开镇纸笔记屏，首屏就是大盘

一眼扫过去：

- **KPI 行**：笔记总数、被用过多少、进过成品多少、带回结账多少；今天捞出几条、花费几分。
- **今天捞到的 · 等你确认**：按押注分组的候选。你逐条扫：
  - 这条确实跟「AI验真局」有关 → **确认挂上**，顺手选它当什么用（论点/案例/标题/反例）。
  - 这条不沾边 → **弃**。弃不是删掉，是告诉系统"这类以后少捞"。
  - 拿不准 → 点"原文"跳 Memos 看一眼再回来。
- **缺料提醒**：哪张押注连捞几轮都是 0 条（库里真没料，该去补研究了）；哪张有料但没人用；哪张只想没产出。
- **最值钱的笔记**：谁的料真进了视频还结了账，分数和走势摆在那。

3 分钟，完事。没有一条笔记正文糊在脸上。

### 白天 你在纸桌想事

正常用：开卡、深挖、改道。某轮回答真解决了问题 → 采纳成金子；某条路走死了 → 立墓碑。这些判决照常同步进 MemOS。

### 傍晚 项目想到了头

打开判决簿，点「项目差不多了」。AI 把这个卡组的问题、分叉、金子墓碑、结论总结成一条笔记草稿。你改两笔，确认，它写进 Memos（带 #决策链 标签）。

**这一下是闭环的关键焊缝**：纸桌的思考从此进了笔记库，明早 06:30 捞料员就能捞到它。

### 创作日 押注变成内容

确认过的料被你拿去写草案、剪视频。每次"被用"都记在这条料的账上：

```
挂上押注 +1 → 进草案 +3 → 进成品 +5 → 结账胜 +10 / 平 +3 / 败 不扣分只挂"待复核"
```

### 结账日 押注到期

数据和结账结论落回来，供过料的笔记身价自动更新。身价榜重排，欠账带里的窟窿要么被填上、要么更显眼。

### 一周后 你回头看大盘

- 确认率从 28% 爬到 39%：你的确认/弃在喂它，捞得越来越准。
- 「从没用过的笔记」那条灰带从 99.8% 往下缩：存量在被盘活。
- 缺料提醒告诉你下一步该研究什么，而不是该整理什么。

## 五个关键时刻的设计意图

1. **候选而非结论**：捞料员永远只提建议，你确认才生效。AI 不决策，这是镇纸的店规。
2. **身价是账本不是评分**：分数全由"引用→草案→成品→结账"的真实记录算出，可点出明细对账。败不扣分——相关不等于因果，裁决权在你。
3. **弃也是养分**：确认和弃都回流，下轮捞取随之调权。这是行业里没人做的"使用反馈复利"。
4. **导出是焊缝**：没有「项目差不多了」，纸桌的思考就烂在图谱里；有了它，决策链变成笔记，明天就能被捞回来。
5. **缺料即选题**：连捞几轮 0 条的押注，说明库里真没货——这不是失败，是系统在告诉你"该去补研究了"。

## 怎么知道闭环在转（度量）

| 指标 | 在哪看 | 健康方向 |
|---|---|---|
| 确认率 | 笔记大盘「近 7 天」 | 缓步上升 |
| 被用过占比 | KPI 行 | 从 <1% 往 5-10% 爬 |
| 从没用过的笔记 | 大盘底部灰条 | 逐周缩短 |
| 缺料提醒条数 | 大盘 | 下降，且剩下的都是"真没料" |
| 决策链笔记数 | Memos #决策链 | 每个收尾项目 +1 |
| 单轮捞料成本 | KPI 行 | ≤ ¥0.10 |

## 现状边界（写旅程时的真实状态）

- 身价公式暂按金子 +10 / 墓碑归零挂"待复核"；判决表没有"平局"态，平局计 0 分是后续需求。
- 捞料来源四类已通：笔记、金子、墓碑、MemOS 记忆；决策链笔记经 Memos 进入笔记源。
- 语义向量检索仍未引入，捞料靠抽词+模型挑选；确认/弃的调权目前是提示词级（近 30 天弃单当反面例子），权重学习是后续。
