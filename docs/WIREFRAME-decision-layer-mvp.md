- 状态：**草稿，待用户认可**（2026-08-08；wayfinder effort：`docs/wayfinder/decision-layer-mvp/`，P01 工单产出）

## 这张稿是干什么的（白话）

把规格里的五块屏摆成一张你能直接看的图：打开协作台这一屏，**什么东西摆在哪、占多大、点什么会发生什么**，全在这张稿里。你认可后，实现批次就照着它动工，做完拿真实截图对着它逐块验收。

## 怎么看（白话）

- 先看第 1 节那张整屏 ASCII：从上到下扫一遍，想想你早上打开它第一眼落在哪。
- 重点核对三件事：①候选卡**两列并排**够不够密（上次你嫌卡片铺满屏太空，这版加密了）②草案区挂在押注卡下、三份各只露一行，是不是你要的秒级 ③弹药架只摆「AI 真引用过的」，空着就空着，不摆"可能相关"。
- 交互只看粗体字：**挑/改/否**、**hover 看明细**、**tab 切视图**、**点押注卡开草案区**、**对话条展开**。其余细节实现时照规格。

## 4. 区块逐项

### B1 顶条
- 左：屏名 + **待你定计数拆两项**（候选 N · 草案 M，与库实时一致；草案计数挂押注卡下的份数）。
- 右：筛子状态小字（**保留现状**，角色重估是雾、本图不动）+ **[收工小结]** 按钮。
- 计数点击 → 锚滚到对应区（候选→B2，草案→第一个带角标的押注卡）。

### 在途押注 rail
- 横滚，每卡：标题截断 + **草案角标 📝×N**（无草案无角标）+ 看结果日小字。
- 点击带角标卡 → 内嵌展开草案区（第 2 节）；点「去深挖 →」→ 层2 单卡深挖（沿用现状）。

### B2 候选对比区（心脏）
- 普通卡**两列网格**，排序分降序，纵滚；每卡**极简三样**：逐字引文 / 来源（uname·赞数·bvid）/ 少数派标记。
- **hover** → 浮层出其余字段：规模代码、挂钩、新鲜度、排序分明细。
- **↗原文** → bvid+rpid 拼 B 站评论锚点新标签（voice 卡无链接不显示）。
- **[挑][改][否]** 沿用 PW-19/20 通路：挑→转内容押注卡；改→overrides 弹层；否→可填理由。
- **少数派区**：虚线金框、单独成区、不参与排序、不与普通卡混排（防平庸·异类保留）。

### B3 弹药架（严格引用层）
- 每条：§N + 金子/墓碑原话截断 + **AI 引用次数 + 最近引用时间**；点开 → 原件全文 + 引用记录（何时/哪条消息/哪份草案）。
- 数据来源=**引用落库**（新建）：AI 标注一次引用就持久化一笔。
- **不摆**"检索命中·未引用"层；检索全走 MemOS，不进屏。
- 空态文案即校验逻辑：空架时 AI 说"我用了金子"=穿帮现场。

### B4 多源可视化块
- 全宽矮带，tab 两视图：①**来源对比**（默认）②**产出榜**；右上时间范围 **近 7 天 ▾ / 30 天**（只控本块统计口径）。
- 来源对比每来源一行：评论数 / 候选数 / 少数派数 / 金子数 / **入决策链数**（候选被挑+金子被引用+草案被定稿合计）；书/文章/笔记行灰显「待来源通路」（R01 缺口③，第一刀容忍）。
- 产出榜：来源 × 产出候选数 / 被挑数 / 被引用次数排行；**主题矩阵不上屏**（暗线攒标签，留雾）。

### B5 对话条
- 底部常驻一条；点击展开**全局对话抽屉 58% 高**（沿用 PW-22）；层2 按卡深挖沿用。
- 对话指认四规、写权限边界（对话即控制台）、查账（list_my_actions）全部不变。

## 6. 空态与边界

- **无候选卡**：B2 显「队列空了——去 agent 窗口抓筛，或在对话条说一句方向」（方向提议在 agent 窗口侧执行，屏上只给入口，不给 AI 提议权）。
- **弹药架空**：空态文案见 B3。
- **无草案**：押注卡无角标，点击不展开草案区。
- **书/文章/笔记来源**：灰行「待来源通路」，不藏不装。
- **voice 卡（无 bvid）**：不显示 ↗原文。

## 7. 沿用不动清单

- 层2 单卡深挖布局（左 60% 三行+素材区 / 右 40% SSE 对话）。
- 对话指认四规、写权限边界（对话即控制台）、审计与冲正。
- 筛子状态小字（顶条右侧保留；后台管线角色重估=雾，不动）。
- 大盘屏、押注台既有屏块（既有纪律）。

## 8. 实现验收核对点（ego 截图逐项）

1. 顶条计数拆两项（候选 N · 草案 M），与库一致。
2. B2 两列并排，1440×900 一屏 ≥4 张普通卡；卡面只有极简三样。
3. hover 浮层出规模/挂钩/新鲜度/排序分；↗原文锚点可点（voice 卡无）。
4. 少数派区虚线金框单独成区，不与普通卡混排。
5. 弹药架只摆实际引用（§N+次数+时间）；空态文案正确；无"未引用"层。
6. B4 两 tab 可切；来源对比含灰行「待来源通路」；默认近 7 天可切 30 天。
7. rail 角标 📝×N 与草案数一致；草案区三份路子行各露一行；骨架点开 5-7 行+§N。
8. 定稿→产出物挂载可见；否掉→bad case 集有记录。
9. 对话条展开抽屉 58%；层2 布局未变。
10. 收工小结弹层数字与当日事件一致，可查账。
