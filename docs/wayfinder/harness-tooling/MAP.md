## Notes

- 项目：镇纸 Paperweight（本仓库 papertableV1）。触发源：2026-08-06 协作台全局对话中 AI 答「我没有落笔/确认这个工具」，用户裁定对话 AI 权限必须重设计。
- 权限模型（2026-08-06 用户原话要点）："AI 必须得有所有读写权限，但决策权在我不能是 AI；我不想动手"——决策=人在对话里下指令（指认页面上哪张卡/哪份草稿）；执行=AI 动手写入；人不动手（不点按钮不翻页面）；AI 不拿主意（无人指令不擅自做状态变更）。
- 与 2026-08-04 纪律的关系：铸币权的实现方式从「能力级 deny」（工具不存在）升级为「发动权在人」（工具都在，须人发话才用）。防平庸条款（原文原则/异类保留/判断留人）不变——决策内容来自人的指令，AI 只起草/摆盘/执行。
- 现状盘点（2026-08-06，src/pw-collab-tools.ts）：17 工具 = 14 allow 只读 + 1 ask（fetch_corpus）+ 2 draft（draft_bet/draft_settle）；deny 即不存在 6 个（settle_bet/create_pending_bet/mirror_golds/pick_sieve_card/reject_sieve_card/create_content_bet）；COLLAB_MAX_TOOL_ROUNDS=4。筛子 run 已自动写 pw_sieve_cards（PW-18，不等指令的唯一自动写先例）。
- 上位规格：《协作台 Harness 目标效果规格》v1（docs/SPEC-collab-harness-effect.md，已验收）——本图是它的工具层落地。
- 关键文件：`src/pw-collab-tools.ts`、`src/pw-collab.ts`（system prompt）、`src/pw-runs.ts`（审计）、`src/main.ts`（路由）、`frontend/src/pw/Collab.tsx`。
- 纪律：每会话只解一票（research 除外）；引用用名字不用编号；规格验收前不写实现代码。
- 长期调试原则（2026-08-06 用户拍板）：Harness 需根据实际情况长期调试——所有定档均为 v1 默认值，可随实际使用修订，修订权在人；"不开放给 AI"一律含"保留人工干预空间"，不解释为永不开门。

- [T01 逐案定档走查](T01-action-grading-walkthrough.md) — 36 动作四档定案：**AI 自主**=起草押注/结账建议、筛子 run（既有）、金子镜像、LLM 声音分拣、语料抓取（取消事前批准，先抓后审+行为限速"AI 读风控信号自行放慢反馈"，审后不设废弃）；**人发话 AI 干**=押注草稿确认/驳回、结账（两跳合一跳，砍批准中间章）、直接建注、挑卡/否卡/全否重筛、录入声音、挂载/摘除产出物、手动补筛、数据文档冻结、押注编辑（补通路 2 个）；**不进对话**=抓取器/同步脚本状态、消息记录、审计落库、水位、连接登记（低频）；**AI 默认不开·人留后门**（用户原则修订："Harness 需长期调试"，不开≠永不开，人保留干预通路，定档为 v1 默认可修订）=删押注/改判决/候选卡回退/水位重置/消息删除/镜像强刷/风控清空，声音提升链留 P2
- [T03 审计与撤销](T03-audit-and-undo.md) — 记账四样（谁干的/干了什么/**听谁的话=人指令引用**/什么时候）+账本只增不改+盲区全补；撤销=误确认作废重起（不退草稿）、新造两个冲正键（撤销挑卡：押注作废+卡退待选 / 结账作废：判决同废可重结）、误冻结不解冻追加版本；擅自发动判定=执行类账缺指令引用（自动断言盯）、审查入口=对话内查账不做专门 UI、店规失效→铸金级升硬闸门 B
