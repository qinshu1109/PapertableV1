# T02 对话指认方式

## Question

人在对话里怎么「指」页面上的对象：候选卡/押注卡/草稿/语料视频的指认方式（短编号、引用块、「就这张」的上下文锚定规则）；全局对话与单卡对话的指认差异；指认有歧义时 AI 的兜底（反问而不是猜）。截图场景（2026-08-06 用户标注）：人在全局对话里指页面上方的候选卡让 AI 代办——这类跨区指认必须成立。

## Resolution

—— 2026-08-06 走查结论（用户确认"认"，关票）——

指认四规：
1. **菜号牌**：AI 摆对象必贴顺口短标签（证据 N / 注 N / 草稿 A / 视频 BV 号），对话里的标签与页面上印的是同一个，指屏说话两边对得上。
2. **就近锚定**：「就这张」= 当前话题卡；AI 刚摆出的列表只有一个候选时 = 该候选。不必每次报菜号。
3. **清楚就干，含糊才问（核心规矩）**：指认明确 → AI 宣告一句（"我把证据 1 挑了"）立刻执行，不复述不等二次确认（人的话已是指令，再等=违背"人不动手"）；指认含糊 → 必须停下来反问，绝不许猜（话直接变动作，猜错=办错）。
4. **单卡对话**默认锚定当前卡（不用指）；**全局对话**必须先列候选再指认。
