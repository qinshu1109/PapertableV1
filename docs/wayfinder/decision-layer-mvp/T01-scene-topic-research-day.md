## Question

走查「发布前选题调研日」在决策层 MVP 屏上的完整用户旅程：从 AI 读原料（本地文件+语料）→ 筛子出候选 → 候选并排比证据 → 弹药架对照 → 挑/改/否/押注 → 对话深挖，逐步过一遍。找出形式缺口：每一步屏上摆什么、缺什么、哪一步还要切出屏外。走查结论直接喂给「F01 决策层 MVP 形式规格」。

注意：既有 docs/SPEC-collab-harness-effect.md 的场景走查是协作台 v1 语境，本票是决策层 MVP 语境下的重走——三块新屏块（候选对比区/弹药架/多源可视化块）都要走到。

## Resolution

—— 走查记录（逐步追加，关闭时汇总）——

**S1 开局（2026-08-08 用户拍板 A）**：屏的脾气=**推式工作台（事找你）**，不是仪表盘。第一眼=**待你定队列**：新筛出的候选卡 N 张（直接落在并排区）+ AI 干了活等发话的草稿/代办，按时间倒序摆最上面。

**S2 抓哪（2026-08-08 用户拍板 C）**：调研方向按场景分两种走法——**有想法时走 A**：人在对话里说一句"今天看看 XX"，AI 去找视频、抓、筛，料进队列叫人（方向永远人下，AI 零提议权）；**没想法时走 B**：AI 依弹药架（金子/墓碑）+ 在途押注 + 多源可视化（哪个方向料少/哪个主题没人碰）摆证据提议几个方向候选，人挑/换/否（提议权给 AI，决定权在人）。**防平庸约束：AI 的提议必须是摆证据（哪个方向料少、哪条金子指向它），不是给结论（"我建议做 XX"）。**

**S3 等料（2026-08-08 用户纠正框架）**：**抓+筛的执行地在 codex/kimicode 等 agent 工具窗口，不在镇纸屏内；镇纸屏=决策面，只展示可供人决策的结果，不为过程再造一层 Harness 监控。** 即：过程流水归 agent 窗口（那边本来就看得见 AI 干活、可控可调，也是直播"用和不用差距"的镜头所在）；镇纸屏只做"到货落待你定队列"。含义待凝（记入 MAP 雾区）：app 内建筛子后台管线（PW-18 的自动 run/watermark 兜底）与"agent 窗口发动"是同一套能力的两个发动面——发动面以后以 agent 窗口为主，app 内自动跑的角色需重估。

**S4 比候选（2026-08-08 用户拍板 A）**：并排区每张卡=**极简三样**：逐字引文 + 来源（谁说的/多少赞/出自哪条视频）+ 少数派标记；规模/挂钩/新鲜度/排序分收进 hover 或点开。证据感最强，合原文原则。排序默认锁死（用户未反对）：排序分降序，少数派虚线金框单独成区不与普通卡混排。

**S5 对照弹药架（2026-08-08 用户两连纠偏后拍板 A）**：规模之问（金子/墓碑可能几百条）先定原则——**全量上架不可能，架上永远只摆和当前决策相关的几条**（AI 上下文方案三上限 10 条同药）。用户否决 kimi 的"机械预筛"方向：**检索复用封装好的 MemOS 混合检索，不自建预筛轮子**；弹药架定位=**使用证据栏**——屏上**只展示 AI 在对话里实际引用过的金子/墓碑原件**（严格引用层，不留"检索命中·未引用"提示层）：AI 说用了没上屏=造假穿帮；架空但回答有金子影子=漏标现场靠人抓+提示词契约。配套新建（唯一）：**镇纸侧引用落库**（AI 标注→verdict id+消息 id 持久化），补 R01 缺口①，补上后引用计数/退役层/产出榜被引用次数全有地基。AI 上下文侧方案三不受影响继续。

**S6 定与收尾（2026-08-08 用户拍板 B）**：挑/改/否/全否重筛沿用协作台现状不动（挑/改→押注卡落在途 rail，否→rejected 可查）。**收工小结**：一天结束屏上出一份「今天定了什么」——挑了几张/否了几张/押了哪几注/AI 代办了几件（吃引用落库+审计账本）；用途二合一：直播"用和不用差距"的现成素材 + 可一键发给 agent 窗口存档。

**走查结论（关票）**：选题调研日在决策层屏上的完整一天——①开局：推式工作台，第一眼=待你定队列（新候选+待发话草稿，时间倒序）；②抓哪：有想法人说一句 AI 跑腿，没想法 AI 摆证据提议人挑（提议摆证据不给结论）；③等料：抓+筛在 agent 窗口跑（过程在那边看），镇纸屏只收到货落队列；④比候选：极简三样（逐字引文+来源+少数派标记）其余 hover，排序分降序、少数派虚线金框单独成区；⑤对照：弹药架=使用证据栏严格引用层（只摆 AI 实际引用过的原件），引用落库为唯一新建；⑥收尾：挑改否沿用现状，收工小结一份「今天定了什么+AI 代办几件」（直播素材+可存档）。**新建清单（喂 F01）**：待你定队列聚合视图 / 并排对比区极简三样改造 / 弹药架引用层+引用落库（补 R01 缺口①）/ 收工小结 / 方向提议（agent 窗口侧摆证据行为）/ 多源可视化块（Q5 已决进第一刀，口径待 T03）。
