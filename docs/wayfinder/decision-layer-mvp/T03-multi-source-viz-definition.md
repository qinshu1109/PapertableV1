## Question

拿「R01 决策层数据资产盘点」的字段清单，把多源可视化块三视图的口径定死：每个视图每列指标的确切算法（"被引用次数"=哪个表哪类事件的计数；"出卡率"=候选数/评论数还是别的；"入决策链"指什么）、主题维度的第一刀取舍（没有主题字段时：人工标 / 借 voice cluster / 先不做主题矩阵）、视图切换与范围过滤（近 30 天）的默认值。产出一页视图定义，喂给「F01 决策层 MVP 形式规格」与「P01 决策层屏线框稿」。

## Resolution

—— 2026-08-08 用户拍板（秒级约束同 T02-S3：一天过数次、每次秒级）——

**主题维度=C 为主 + B 做暗线**：①视图级 C——第一刀屏上只放**来源对比 + 产出榜**两个真实数据视图（评论数/候选数/少数派数/被引用次数，每行当场可验、秒级可信），**主题矩阵留雾不上屏**；②标签级 B 暗线——AI 后台顺手给候选/金子打主题标签（LLM 分拣），**只进库不进屏**，人不看不改不背打歪成本，攒几周覆盖够且抽查靠谱后再开主题矩阵上屏（开即是熟视图）；③否决 A 人工顺手标的理由：挑/否主路本来就是秒级决策，每张卡再加"什么主题"微决策=每次判断加一秒，一天数次正好把秒级拖成分钟级，违反用户自定约束。

**指标口径**：出卡率=候选数/评论数；被引用次数=引用落库后按金子计数（吃 T01 新建）；**入决策链=该来源的产物进入决策动作的三类事件合计（候选被挑 / 金子被引用 / 草案被定稿）**——三类均有或将有望有落库（挑改否/引用落库/定稿挂载）。

**范围过滤**：默认**近 7 天**（匹配一天数次节奏），可切 30 天；第一刀两个档位。
