# Q00 语料评论分区烤问

## Question

观众声音屏语料评论分区是逐条原文列表（like 降序 top50/视频），评论量级数千判不动：这一区的拍板单位是什么、卡的出口通到哪、聚合怎么触发。

## Resolution

—— 三问逐条，2026-08-11 用户逐问拍板 ——

**Q1 拍板单位 = 主题卡 + 逐字证据（赞数进证据面）**：AI 把一个视频的评论按主题聚成少量卡，卡下挂逐字评论原文（作者/赞数/时间齐）；人判的是「这个观众主题值不值得收」，证据随时验真。（落选：AI 批量预收录进声音列表——「看上哪条点收录」的人审入口没了，几千条冲垮声音列表；只加统计摘要层——高频词不是概念，还得读原文，治标。）

**Q2 卡出口 = 整卡收录 + 弃**：整卡收录 = 卡内评论逐条进 `pw_voice_items`（platform=bilibili:{bvid}、content 逐字），PW-26 自动分拣挂钩自然触发，已收录的逐字防重跳过；收录后单条提请仍走 PW-45 既有链，不另立状态机。弃 = 卡 rejected，重聚时该卡覆盖的评论不再浮出。评论场景不立 self_memory/link_shell 卡型（那是笔记决策记忆回流的元问题，这里没有）。

**Q3 触发 = 手动「聚一下」，不做自动**：每个视频第一次点即首聚（4 个已抓视频即是迁移）；重聚同按钮（suggested 卡重排，collected/rejected 卡与其评论一律不动、不进输入）。新视频抓完自动聚、评论增量自动重聚都押后，用顺手再凝。
