## 范围

在现有 Papertable 前端（React 18 + Vite，`frontend/src/`）中新增 Paperweight 区域，与探索界面共存：

1. **区域入口与导航**：App 增加轻量视图切换（探索 / 镇纸），镇纸区内三屏（押注台 / 金子墓碑库 / 大盘）+ 顶部导航。样式沿用 `styles/base.css` 的纸感 token（暖纸底、卡片、墨色、金/石碑色），不引入新 UI 框架、不加 react-router（用 state 切换即可）。
2. **押注台（PW-02）**：单卡驾驶舱。押注列表（非 draft）选卡；主卡显示三行赌注（验证指标/数据来源/结账日）+ 置信度 + 距结账日天数 + 状态徽章；产出物列表（`GET /api/pw/bets/:id/artifacts`）；数据文档列表（`GET /api/pw/bets/:id/data-docs`）；时间线回放（`GET /api/pw/bets/:id/timeline`）；装配上下文只读展示（`GET /api/pw/bets/:id/context`）。操作：新建押注（`POST /api/pw/bets`）、手动挂产出、手动录数据文档、到期卡走结账弹层（铸金填 lesson / 立碑填死因 / 作废），`POST /api/pw/bets/:id/settle`。
3. **金子墓碑库（PW-06 界面部分）**：金子/墓碑列表（`GET /api/pw/verdicts`）、关键词检索（`GET /api/pw/verdicts/search?q=`）、墓碑死因聚合计数（`GET /api/pw/verdicts/tombstone-stats`）、镜像金子区（`POST /api/pw/gold-sync/mirror` 触发同步 + `GET /api/pw/golds` 列表）。
4. **大盘（PW-10）**：目标进度卡（Q3 示例目标 + 已完成/押注中计数，来自 `GET /api/pw/bets` 与 `GET /api/pw/verdicts` 聚合）；判断力账本（金子/墓碑/押注中三数字 + 置信度样本 ≥5 时出校准曲线——10 档分桶：宣称置信度均值 vs 实际 gold 率，SVG 手绘风折线 + 对角虚线，样本不足显示"样本还少，N 次结账后再看"）；近期判决列表。
